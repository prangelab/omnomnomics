# Contributing

Thank you for your interest in omnomnomics. The project is developed and
maintained by a small research lab, and we do not currently have the capacity to
review, validate, support, and maintain unsolicited pull requests. We are
therefore not accepting external code contributions or feature PRs.

Reproducible bug reports are welcome through GitHub Issues. Please include the
omnomnomics version, assay, command, relevant configuration, and the smallest
log excerpt that demonstrates the problem.

Forks remain welcome under the repository license.
